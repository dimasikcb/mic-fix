# 🎤 Восстановление встроенного микрофона (Windows)

Скрипт автоматического восстановления аудиоподсистемы Windows для ноутбуков.

---

## 🚀 Запуск

Правый клик по **[fix-microphone.ps1](file:///C:/Users/admin/.gemini/antigravity/scratch/mic-fix/fix-microphone.ps1)** ➔ **«Выполнить с помощью PowerShell»**  
*(или запуск из консоли PowerShell)*.

Скрипт **автоматически запросит права администратора (UAC)**, если запущен из-под обычного пользователя.

---

## 📊 Что происходит при запуске (новый интерфейс):

1. **Динамический прогресс-бар**: наглядно показывает текущий шаг, процент выполнения (`0% ➔ 100%`) и таймер обратного отсчёта (`осталось ~X сек`).
2. **Шаги восстановления**:
   - `15%` — Активация точки микрофона в реестре Windows (`DeviceState = 1`).
   - `40%` — Перезапуск служб Windows Audio (`Audiosrv`), `AudioEndpointBuilder` и `Nahimic`.
   - `60%` — Проверка и открытие разрешений конфиденциальности Windows.
   - `80%` — Перезапуск PnP-стека `AMD Audio Device` и пересканирование шин оборудования (`pnputil`).
   - `95%` — Снятие программного мьюта и установка громкости на 100%.
   - `100%` — Замер входного сигнала микрофона в реальном времени.
3. **Итоговая карточка**: выводит понятный статус (готов к работе / требуется перезагрузка), уровень громкости и активность сигнала.
4. **Логирование**: все отчёты аккуратно сохраняются в папку `logs/`.
